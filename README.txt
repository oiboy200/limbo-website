LIMBO — WEBSITE

Sito statico responsive con homepage, Projects, pagina progetto Japan, About, Custom Frames e Contact.

APERTURA LOCALE
Estrai la cartella e apri index.html. Per il normale test locale puoi usare un server locale (ad esempio l'estensione Live Server di VS Code).

CMS
Il pannello Decap CMS è predisposto in /admin e le istruzioni sono in CMS-SETUP.md. Per usarlo online servono un repository GitHub e un hosting collegato (configurazione una tantum). Il pannello non salva modifiche se apri semplicemente index.html dal computer.

PERSONALIZZAZIONE
- Testi: file HTML (e, dopo l'attivazione CMS, contenuti in content/)
- Immagini: assets/ e uploads/
- Font, colori, dimensioni e responsive: styles.css
- Animazione logo: site.js

Prima della pubblicazione sostituire email/social/indirizzo provvisori, approvare i testi e sostituire eventuali immagini dimostrative.
